ARAVI INSTAGRAM OUTREACH — WINDOWS PROTOTYPE

Extract the entire ZIP. Open AraviOutreach.exe inside the AraviOutreach folder.
Keep the _internal folder beside the EXE. No Python installation is required.

Enter your sender username, import Excel/CSV profile links, and paste your message.
Open the login browser and log in yourself. Set Instagram language to English.
Use Prepare one draft first with a team-owned test profile. It does not send.
Clear that draft manually. Start batch only after reviewing recipients/message.

Live Instagram sending has not been verified. The app stops if it cannot verify
sender/recipient or detect the required controls. UI changes can require an update.
The results describe attempts, not delivery receipts. Review in Instagram.
No account safety guarantee; 25 per batch is an app limit, not a safe-send limit.

Session and records are local in AraviOutreachData in your user home folder.
Never share that folder. Stop may not cancel an already in-progress send.
Handle replies manually in Instagram. No direct Google Sheets connection yet.
